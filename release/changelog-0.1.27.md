# 0.1.27

- **Fine-tune any slider.** Every slider in the settings now has **<** and
  **>** buttons that move it one step at a time (1 px for **Bar width** and
  **Swing bar width**, 0.05 for **Display size**), plus a box where you can type
  an exact value and press Enter. Values outside a slider's range are set to
  the nearest limit, and Escape puts the current value back. For font sizes and
  **Essential icon size**, the arrows jump straight between 0 (the default) and
  the smallest custom size.

Targets Forever beta 1.60.1, interface 16001.
