# 0.1.26

- **New layout: Blizzard Cooldown Manager.** If you track your seals in
  Blizzard's own Cooldown Manager, choose this layout on the **Layout** page (or
  type `/psc style blizzard`). Pally Seal Cooldowns then draws nothing on screen
  and only plays its alerts: the refresh sound and the missing-seal sound.
  **Refresh warning** on the General page still sets how many seconds before
  your seal ends the refresh sound plays. The settings pages show only the
  options that apply to this layout. Add your seals in Blizzard's Cooldown
  Manager settings.

Targets Forever beta 1.60.1, interface 16001.
