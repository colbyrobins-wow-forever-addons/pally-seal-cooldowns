# Seal rank data attribution

The seal rank IDs used by the native display come from talentsforever.com:
https://talentsforever.com/data.json

The data was adapted from the installed ForeverAuras rank dataset dated
2026-09-24, which attributes its source to talentsforever.com and licenses the
rank data under Creative Commons Attribution 4.0 International:
https://creativecommons.org/licenses/by/4.0/

Changes in this addon: retain paladin seal rank IDs, combine them into a native
display filter, and retain the addon's existing spell ID 21084 alias. No
ForeverAuras implementation code is included. The display uses Blizzard's
native aura-container API independently; ForeverAuras is not a dependency.

This notice concerns the rank data and does not assign a license to the rest
of the addon. No endorsement by the data source or Blizzard is implied.
